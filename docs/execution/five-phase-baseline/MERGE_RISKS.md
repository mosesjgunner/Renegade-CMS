# Merge-risk register

| Hot spot                                                     | Owner/rule                 | Why parallel edits are risky                                                                                                           |
| ------------------------------------------------------------ | -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `src/modules/payload-domains.ts`                             | Domain registration owner  | One ordered registry; omission or duplicate breaks Payload registration/type tests.                                                    |
| `src/payload.config.ts`                                      | Platform owner             | Couples auth collection, DB adapter, globals, task execution, admin import map and generated types.                                    |
| `src/migrations/index.ts` + new migration                    | Migration author           | Append-only ordered ledger. Never edit an applied migration; append one migration, register it once, and verify fresh + upgrade paths. |
| `src/payload-types.ts` and migration `*.json`                | Generated-file owner       | Generated by Payload. Do not hand-edit; regenerate after source schema/migration change and commit the matching output.                |
| `src/collections/canonical-shared.ts`                        | Architecture owner         | Scope, retention, SEO, visibility and ownership fields fan out through nearly every record.                                            |
| `src/modules/core/contracts.ts`                              | Architecture owner         | Branded IDs and cross-domain vocabulary; changes require an ADR/contract test review.                                                  |
| `src/modules/core/config.ts`, `.env.example`, Compose/Docker | Operations owner           | Configuration policy must agree across application, docs, image and runtime deployment.                                                |
| `src/modules/public/*` and catch-all route                   | Public-boundary owner      | A small projection change can disclose private, held, expired or unlisted data.                                                        |
| `src/modules/extensions/contracts.ts`                        | Extension-boundary owner   | Provider/plugin compatibility and secret ownership are shared by all external adapters.                                                |
| `src/modules/*/tasks.ts`, worker script                      | Domain + operations owners | Retry, concurrency, audit and idempotency must agree with each domain's durable records.                                               |
| `PROJECT_STATE.md`, `docs/release/*`                         | Release owner              | Existing history contains stale/contradictory claims; update only with current executable evidence.                                    |

Current uncommitted hot spots that must be treated as somebody else's work until coordinated: `.env.example`, `.env.production.example`, `PROJECT_STATE.md`, collaboration collection/service/realtime routes and migration, `src/migrations/index.ts`, `src/payload-types.ts`, core config, identity payload domain, worker runner, commerce webhook route, and their associated tests.
