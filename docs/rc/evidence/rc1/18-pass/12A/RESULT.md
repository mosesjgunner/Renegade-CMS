## Ordinary journey and persistence

Supported operator HTTP APIs upload a private PNG, create immutable monthly `1200 USD / month` and annual `12000 USD / year` plans, and publish an entitlement-protected article. A canonical-service fixture member session opens `/members/settings?tab=billing`, observes both prices and clicks **Start Journal monthly 12A**. The actual Stripe-test adapter reads the harness price, creates the hosted session with server correlation metadata, and Chromium reaches the visibly labeled isolated payment page.

Before payment the stored subscription is incomplete and its linked order is pending-payment. Reusing the same signup key returns the original subscription with no second provider checkout. A signed subscription event grants exactly `journal12a.read` and `media:<id>.download` for the purchaser and Alpha site. Activation leaves the order unpaid. Clicking **Confirm harness payment** sends a signed paid-invoice event through the supported webhook; the canonical order becomes paid and its checkout session completed. Billing shows active status and the provider period/next billing date. The member observes `SUBSCRIBER-SECRET-12A` and downloads bytes equal to the uploaded private original.
