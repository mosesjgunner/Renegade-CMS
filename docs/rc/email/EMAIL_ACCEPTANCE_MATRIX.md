## Known limits (not hidden)

- Token issuance and intent creation are two writes joined by compensating revocation,
  not one transaction (documented in EMAIL_CONTRACTS.md §3).
- Account-worker hard _secret_ isolation requires a separate deployment environment;
  the shared Compose environment block is documented as readable by both containers.
- The 10k-delivery load row of EMAIL-10 was exercised at reduced scale only.
- SES fallback adapter not implemented; documented fallback decision for the owner if
  Postmark approval/boundary confirmation fails.
- Postmark webhook correctness is code-proven only; no live event received.
