## Shared interfaces for later passes

| Interface          | Required inputs and result                                                                                                                                                                                                                      |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Actor and scope    | Server resolves current member or operator, effective site, optional Space, and role/capability. Return a scoped decision and deny on missing or suspended authority.                                                                           |
| Transition command | Actor and scope, aggregate ID, expected revision, requested edge, client key and canonical request hash. Return committed revision and event ID or a conflict. Persist the aggregate and outbox together.                                       |
| Asset reference    | Site, asset ID, immutable source revision or checksum, optional rendition ID and usage. Resolve authorization again when issuing playback access.                                                                                               |
| Provider attempt   | Site, authorized provider account, operation, attempt ID and input hash. Return remote reference and observed status or a classified failure. After an uncertain outcome, reconcile by the same attempt key before starting a separate attempt. |
| Job claim          | Tenant, job ID, input revision, attempt, lease expiry and fencing token. Completion records output checksum. Approval and publication remain separately authorized transitions.                                                                 |

Use canonical serialization for hashes and a unique tuple of site, actor, operation and client key. Store the hash beside that tuple so a changed payload conflicts. Upload chunks additionally bind session, index, byte span and checksum. An end-event retry binds the original event and end operation, so it cannot create a second replay. Provider import identity binds provider, authorized channel and external item. These contracts are proposals. Existing room and upload retry behavior and the synthetic provider contract are exercised independently.
