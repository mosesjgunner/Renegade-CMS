# Creator Studio captions and dubbing

Open **Creator Studio → Media editor**. Add an owned video, then open **Captions and chapters**. Create cues against timeline time or import a WebVTT or SRT file. Use a cue timestamp to move the preview. The subtitle selector can show the timeline captions, a selected source transcript revision, or no subtitles. Download the timeline as WebVTT or SRT.

For a single clip, **Save captions as reviewed revision** creates an immutable source transcript revision. The same source can have multiple revisions. Waveform and provider jobs are available under **Source transcript and waveform**. Refresh source results to inspect the waveform or drafts. Select **Replace timeline captions with this revision** to copy a draft into the editor for human editing and review.

Under **Voiceover**, use the recorder or select an owned audio file and set the start offset. **Replace audio (manual dub)** exports the replacement as the default MP4 audio stream. The export includes a selectable source stream. A full, zero-offset MP4 clip with a compatible AAC track keeps the original AAC packet data. Edited timelines export a labeled timeline source mix. The original media asset stays intact. Landscape and vertical MP4s include a labeled subtitle track when the timeline has cues.

## Optional workers and providers

Run the existing worker with `WORKER_PROFILE=media-heavy`. Use the same provider configuration on the web and worker processes. Manual editing and sidecar downloads work without an AI account.

- **Transcription** uses the existing Podcast Studio configuration. Set `PODCAST_TRANSCRIPTION_PROVIDER=command-provider` and `PODCAST_TRANSCRIPTION_COMMAND` for a local executable, or use `http-provider`, `PODCAST_TRANSCRIPTION_ENDPOINT`, and an optional `PODCAST_TRANSCRIPTION_API_KEY`. Video transcription sends extracted mono WAV. Providers return `{ language, segments: [{ start, end, text }] }`. The creator must opt in before queueing.
- **Subtitle translation and clip suggestions** use `CREATOR_TRANSCRIPT_ASSIST_COMMAND` or `CREATOR_TRANSCRIPT_ASSIST_ENDPOINT` with optional `CREATOR_TRANSCRIPT_ASSIST_KEY`. A local executable receives a JSON filename and writes JSON to stdout. An HTTP adapter receives that JSON as the POST body. The input includes `operation`, `segments`, and `language` for translation. A translation returns `{ texts: string[] }` in cue order. Clip suggestions return `{ clips: [{ start, end, reason }] }` in source seconds. Translation preserves cue timings and creates a separate draft. Suggestions remain reviewable ranges.
- **Synthetic dubbing** uses `CREATOR_DUB_COMMAND` or `CREATOR_DUB_ENDPOINT` with optional `CREATOR_DUB_KEY`. Set `CREATOR_DUB_VERIFIED_VOICES` to a JSON map of `"site UUID:member UUID"` to provider voice ID only after verifying the speaker's enrollment. An enrolled creator can grant permission for their own voice on a saved project and reviewed transcript revision with approved source rights. The adapter receives `{ voice, duration, cues: [{ start, end, text }] }` in timeline seconds. A local executable receives the JSON request filename and output WAV filename. An HTTP adapter accepts JSON and returns a WAV body. Supply a full-duration, 16-bit PCM WAV at 8–48 kHz with one or two channels. The worker adds embedded provenance. Review the private result before downloading it. Revoking permission removes access and deletes the stored draft. Voice conversion and lip-sync are unavailable.

## Acceptance measurements

On an isolated PostgreSQL database, Chromium edited three manual cues and placed replacement audio at the corresponding times on a 60-second source. Both landscape and vertical exports decoded successfully and contained the default **Manual dub**, selectable **Original source audio**, and **Creator captions** tracks. The source file SHA-256 stayed byte-identical. The AAC payload hash matched the original in both exports.

FFprobe reported cue starts of 3, 27, and 57 seconds. Decoded 48 kHz PCM crossed the onset threshold about 0.042 ms after each cue in both variants, within the 34 ms tolerance. The replacement take used identifiable test pulses to measure alignment. Chromium also recorded and finalized a separate audio take using a test microphone.

A local HTTP fixture exercised transcription, subtitle translation, clip suggestions, and synthetic WAV synthesis. Existing human-edited captions stayed intact. Synthetic requests with missing rights, missing consent, or the wrong voice were denied. A second member could not read the draft. Download required review, and revocation removed access. An interrupted waveform claim was recovered and completed by the restarted heavy worker. The fixture verifies the protocol and permission flow. Speech quality and real-provider timing remain unverified.
