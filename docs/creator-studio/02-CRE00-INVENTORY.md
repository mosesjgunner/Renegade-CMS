## Proposed registration ownership

Identity/Space grants belong with the existing identity registration and site-scoped policy; canonical album/media/usage fields belong to the editorial domain floor; optional media capture, editing, live and processing belong in `src/modules/media/payload-domain.ts` and the relevant `media-studio` manifest claims; Rooms/theater extend existing community services and its documented editorial-domain registration exception; outbound provider distribution extends social registrar and `social` manifest. Existing creator catalog must be reused. This is a proposed mapping, not proof that new relationships are valid in every module profile. For each new collection or task, validate registrar ownership, manifest filtering, optional relationships, count limits, fresh and upgrade migrations before implementation. Existing `media-studio` manifest does not list every task present in the media registrar; do not assume a task is disabled merely because it is media-related.
