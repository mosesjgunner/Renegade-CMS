# CRE-06 External video and distribution

Open **Creator Studio → External videos and distribution**. Connect a YouTube channel to browse the uploads playlist and import individual videos as private draft content. Add public Vimeo links, approved direct MP4 or WebM URLs, or approved HTTPS player URLs from the same screen. Use the ordinary editorial workflow to review and publish the linked content.

Renegade keeps the provider snapshot separate from the draft. It matches each source within the site by a SHA-256 digest of `provider:scopeId:externalId`. An import or refresh updates provider facts and retains the original content ID, body, editorial status, and authored title. Until a creator names the draft, Renegade displays the current provider title. Private, unlisted, removed, unavailable, disconnected, and expired YouTube sources have no public player. Detaching a source removes its playback and metadata locally. Manage remote edits and deletions in the provider dashboard.

## Enable YouTube on an authorized test installation

- Set `CREATOR_YOUTUBE_AUTHORIZED=true` together with `CREATOR_YOUTUBE_CLIENT_ID`, `CREATOR_YOUTUBE_CLIENT_SECRET`, `CREATOR_YOUTUBE_ALLOWED_CHANNELS` (comma-separated YouTube channel IDs), and the installation’s 64-hex-character `RENEGADE_ENCRYPTION_KEY`.
- Register the exact HTTPS `CREATOR_YOUTUBE_REDIRECT_URI` ending in `/api/creator-studio/external-video/callback`. Grant `provider.connect` to the creator and `content.draft-own` for their Space.
- Creator authorization uses Google’s read-only scope, PKCE, and a short-lived encrypted state cookie bound to the member and site. Renegade checks the channel through `channels.list(mine=true)`, then checks each video’s channel before accepting its metadata. Only the encrypted refresh credential is stored. Keep OAuth callback query strings out of proxy access logs.
- Disconnect in Studio or use Google Account permissions. On detected revocation Renegade removes cached provider facts and credentials, preserving the authored content and opaque source identity. The jobs worker rechecks aged authorizations and purges YouTube snapshots after 28 days. Refresh an existing source in Studio, or select it from the channel catalog again after expiry.
- For a separately authorized upload test, also set `CREATOR_YOUTUBE_UPLOAD_AUTHORIZED=true`. In the YouTube Social Studio account, enter the authorized channel ID and an encrypted credential containing the Google refresh token issued to the configured OAuth client with both `youtube.readonly` and `youtube.upload` scopes. The creator import grant is read-only.
- Attach one native video to a YouTube Social Studio variant. In its `youtubeUpload` field set `channelId`, `title`, `privacy` (`private`, `unlisted`, or `public`), `madeForKids` (`yes` or `no`), and `complianceConfirmed` after verifying rights and YouTube Community Guidelines compliance. Approve, then schedule the variant. Renegade accepts private uploads by default. Set `CREATOR_YOUTUBE_PUBLIC_UPLOADS_AUTHORIZED=true` only for an approved project explicitly authorized to test public or unlisted uploads.
- The worker prepares a Google resumable session after rechecking scopes, channel and local media policy. It opens byte ranges on local disk or object storage, probes the same session after transport failures, and honors provider quota responses. Ambiguous outcomes and worker interruptions go to the existing reconciliation queue for review in YouTube Studio.
- For manual URLs, configure exact comma-separated HTTPS origins in `CREATOR_DIRECT_VIDEO_ORIGINS` and `CREATOR_CUSTOM_EMBED_ORIGINS`. Direct video hosts need anonymous CORS access. Vimeo accepts public video IDs. These paths allow browser playback and report unverified provider availability.
- Choose **Export for manual upload** to download an eligible owned original for upload in a destination dashboard. Social Studio stages manual handoffs as approved copy and attachment references. YouTube analytics, thumbnail writes, remote edits and remote deletions are outside the adapter’s supported operations.
