# Podcast Studio — documentation index

Renegade Podcast Studio is the native podcast desk inside Renegade CMS:
show management, production, recording, editing, rendering, live output
and publishing in one self-hosted system. It is a clean-room native
implementation (see `THIRD_PARTY_NOTICES` at the repo root for the
pattern-level MIT adaptations and the provenance register).

Start here:

- [SELLER_NOTES.md](SELLER_NOTES.md) — what the package is, what a
  podcaster gets at each level (L1–L4), what an operator must provide,
  and the plain-language "not yet" list. Every claim there is backed by
  the POD-20 acceptance evidence.
- [PODCAST_PROJECT_STATE.md](PODCAST_PROJECT_STATE.md) — the technical
  state of the program: what each stage built, the evidence for it, and
  the open findings.
