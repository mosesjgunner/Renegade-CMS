## Registration / schema additions (all additive, one migration)

New collections in `src/collections/Monetization.ts`, registered by a
new `monetization` domain (appended last in payload-domains) and
claimed by a new `monetization` module: `monetization-profiles`,
`provider-connections`, `external-revenue-evidence`,
`sponsor-advertisers`, `sponsor-inventory`, `sponsor-bookings`,
`representation-agreements`, `ad-placements`, `rights-records`,
`license-offers`, `license-grants`, `service-bookings`,
`distribution-submissions`. Provider catalog entries are code-defined
constants (descriptive data versioned with the code + doc-review
dates), served by API — not a table. Products gain two additive
`kind` select options in the CE migration: `service` (CE-02,
booking-backed) and `license` (CE-10, grant-backed) — additive enum
values, no data rewrite. Every counting/listing expectation that enumerates product
kinds, collections, modules, domains or migrations is updated in the
same commits (registration-expectation rule).
