Every provider named in the pass contract's Appendix A, dispositioned
against HEAD. Modes are the contract §5.1 dimensions. **No provider is
`NATIVE_VERIFIED`** — no live monetization account, agreement or
credential exists for any of them, and none may be created in this
pass. "Build" below means: catalog entry with accurate modes/caveats

- the named functional path (import/manual/external workflow or a
  mock-tested adapter). Live legs stay **blocked** with the gate named.
  Documentation basis: Appendix A (researched 2026-11-22 from official
  provider docs); entries carry `documentationCheckedDate` in the code
  catalog and stale/conflicting eligibility is surfaced as "check
  current provider review", never hard-coded truth (Mediavine/Ezoic
  threshold conflicts are recorded as conflicts, per Appendix A §9).
