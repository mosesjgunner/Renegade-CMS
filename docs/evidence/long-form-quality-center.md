# Long-form/books and Unified Site Quality Center

Books reuse canonical `content`, the public catch-all renderer, `buildMetadata`, local discovery, Payload jobs, and `public-redirects`. A book has ordered parts and chapters; each chapter has a stable canonical path, publishing state, release instant, manuscript relationship, and optional footnotes. Public rendering provides an accessible table of contents and labelled previous/next navigation. It deliberately does not add reading-progress storage because no existing reader-progress contract exists. Chapter manuscript citations and bibliography remain the established `article-family-content` fields.

Changing a book content canonical path uses the existing Content redirect hook. Changing a chapter canonical path creates an exact 308 redirect in the same site scope. Reordering changes navigation only, never a chapter URL.

Quality Center has one site-scoped issue record keyed by rule, target, location, and tenant. Local scans cover malformed canonical URLs, heading-level skips, missing image alt text, expired image rights, unavailable or unpublished internal references, and stale/incomplete translations. The external-link helper remains provider-disabled/advisory: it emits an uncertain warning and never prevents a local scan from completing. Provider/AI suggestions are intentionally not scan prerequisites.

Lifecycle: queued -> running -> completed/failed/stale; issues open/uncertain -> resolved when absent from a later scan, reopened when returned, or ignored/waived with retained reason/timestamp. Ignore requires an owner, a reason, and a non-blocking finding. Waivers retain the existing separate authorization record. Each issue carries a deterministic repair URL. `markStaleQualityScans` makes abandoned worker leases explicit and requires a rescan.

Coverage proof is in `tests/unit/long-form-quality.test.ts` (ordering, local deterministic rules, tenant-aware dedupe, and disabled-provider behavior), `tests/integration/media-acceptance.integration.test.ts` (published ordered chapters), and `tests/integration/long-form-quality-center.integration.test.ts` (chapter redirect, duplicate-safe scan, repair/rescan resolution, false-positive ignore, tenant rejection, and stale lifecycle). The database suite needs PostgreSQL plus migrations applied; the scan task itself reuses the standard Payload worker contract.
